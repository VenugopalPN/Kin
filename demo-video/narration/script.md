# Kin feature tour narration

Each `##` heading is a scene id from `scripts/scenes.mjs`. Every other non-empty
line is one subtitle cue and one spoken sentence. Write `{shown|spoken}` when the
subtitle and the speech should differ.

## intro
Welcome to Kin.
This platform is designed to streamline your fundraising.
Pick a door: Platform, Campaign, Promoter, or Donor.
Let's take a complete tour of the interface and its features.

## core
Let's look at our core workspace.
First, we have the Create a website chat, which builds an organization's public website.
Fill demo values answers it for you, and a demo email shows the admin how to sign in.
Right next to it is Create a fundraiser, designed to let you answer one question: what should the money buy?
Kin writes the draft as you type, and Write the fundraiser publishes it instantly.

## customize
For deeper control, we use the Manage the fundraiser page and its sidebar.
Under Amounts, press Change on any gift to rename it.
The Hide dollar amounts on the leaderboard toggle keeps totals private.
The Website tab reopens the Edit website chat to update your public page.
And Show the wall opens a full-screen thank-you wall.

## output
Once processed, we move to the Leaderboard, which ranks promoters by how much their personal links raised.
A promoter shares their note from Send the note, and supporters find the fundraiser on the public website.
The Give page records a gift. In this demo, no money changes hands.
Back on the Leaderboard, Elena Rossi's bar updates in real time.

## data
Finally, Send links to promoters lets you tick helpers and send each a personal link.
This is a demo, so nothing is really sent.

## outro
And that is a complete look at Kin and its features.
Try it out for yourself today!
